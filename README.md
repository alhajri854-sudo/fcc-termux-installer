# Free Claude Code Termux Installer

تثبيت `free-claude-code==6.19.11` على Termux بأمر واحد مع تهيئة `grpcio==1.85.1` تلقائياً.

## أمر التثبيت السريع

    pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/alhajri854-sudo/fcc-termux-installer/main/install.sh | bash

## سجل الأخطاء

في حال حدوث أي مشكلة أثناء البناء، راجع ملف السجل:
`$HOME/fcc-install-native.log`
